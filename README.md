# TCSRNet: Target-Cue Structure Reconstruction Network for Infrared Small Target Detection

TCSRNet is a target-cue-driven framework designed for infrared small target detection in complex backgrounds. It introduces potential-target references to improve target-background discrimination, boundary recovery, and hierarchical semantic feature reconstruction.

The framework incorporates three key components:

- **LDTR (Local Discrepancy-Guided Target Reference):** Constructs discriminative target cues through local response discrepancy modeling and adaptive contextual selection.
- **LGBI (Low-Frequency-Guided Boundary Interaction):** Enhances target boundary representations through low-frequency contextual guidance and target-reference constraints.
- **TRHR (Target-Response Hierarchical Rectification):** Improves hierarchical semantic alignment through target-conditioned sampling and residual-guided feature reconstruction.

The proposed components establish a target-cue-driven reconstruction process to enhance infrared small target detection under challenging background conditions.
